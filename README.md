## 🖼️ Design Style (For Your Reference)

- **Colors:** Navy `#0b1d36` + Gold `#c89b3c` + Cream `#f5f0e6`
- **Fonts:** Playfair Display (headings) + Inter (body)
- **Animations:** Marquee ticker, 3D logo spin (CSS `perspective` + `rotateY`), float orbs, smooth scroll
- **Responsive:** Mobile → Laptop → Desktop → TV
- **2D / 3D:** Header logo is 3D spinning; cards/images are 2D with hover zoom; floating buttons are flat
gold-rounded

## 🚀 Deploy in 2 Steps

### Option 1 — GitHub Pages (This Repo)
1. Push `index.html` + `public/` folder to `rahulselokar27-collab/shree-developers-nagpur-site`
2. Repo Settings → Pages → Source: `main` branch / `(root)`
3. Site live at `https://rahulselokar27-collab.github.io/shree-developers-nagpur-site/`

### Option 2 — Direct File (No Build Needed)
- This is a pure HTML/CSS file — no `npm install` required for the final output
- Open `index.html` locally or upload to any static host (Netlify, Vercel, Surge)
